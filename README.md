# Jutsu Studio for Homebrew

```bash
brew install jutsuhq/tap/jutsu-studio
```

[Jutsu Studio](https://github.com/jutsuhq/jutsu-studio) is an unofficial native Mac app for Higgsfield video and image generation. It updates itself; `brew upgrade --greedy` updates it through Homebrew.

The cask in `Casks/` is updated automatically when a release of jutsuhq/jutsu-studio is published.
